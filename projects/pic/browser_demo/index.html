EPDE vs SINDy

EPDE — original Python framework

Constructs candidate equations from tokens and derivative terms, uses sparsity fitting, and evolves systems under multiple objectives. The official code depends on native Python packages including PyTorch, so this browser edition does not run EPDE itself.

PySINDy — runs here in the browser

Builds a fixed library of candidate features, then uses sparse regression to select a few non-zero terms. We load the official 2.1.0 library directly into Pyodide.

Original EPDE LikeC4 architecture

Run the original EPDE (no rewritten algorithm)

The browser-only edition cannot load the original PyTorch-dependent EPDE engine. For exact native EPDE on your own Windows computer, there is an optional one-click launcher that automatically downloads the original source and locked Python environment (large first-time download). It needs your explicit permission to open the program; a web page cannot do this silently.

Windows native EPDE launcher · source and instructions ↗

Native launcher status is tested separately. For PDE work, the browser-only PySINDy demo currently supports only ODEs. Full PySINDy itself has PDE and implicit-equation libraries; the shipped benchmark adapter has additional restrictions.

Understanding the results

Derivative R² compares predicted and numerically estimated derivatives on the recorded trajectory. The validation tail contains the last 20% of time levels. This is not an independent trajectory forecast or proof that the recovered equation is physically correct.
