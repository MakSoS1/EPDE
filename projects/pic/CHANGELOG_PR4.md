# PR4 — воспроизводимая установка через uv

Добавлены описание зависимостей и lock-файл для `projects/pic`.
Исправлены команды запуска: выбранная сборка PyTorch сохраняется и при установке,
и при последующем запуске примеров.

1. **Зависимости — [pyproject.toml](pyproject.toml).**
   Собраны пакеты EPDE, загрузчиков, baseline и ноутбуков. EPDE подключается
   из этой рабочей копии в editable-режиме, чтобы изменения кода были доступны
   без переустановки пакета.

2. **Версии — [uv.lock](uv.lock).**
   Зафиксированы совместимые версии и зависимости. Это заменяет ручной подбор
   пакетов и позволяет воспроизводить окружение для примеров.

3. **PyTorch и команды запуска — [pyproject.toml](pyproject.toml), [README.md](README.md).**
   Сборки `cpu` и `cu128` оформлены как взаимоисключающие опции со своими индексами.
   В каждом `uv run` явно указан выбранный extra. Раньше после `uv sync --extra cpu`
   обычный `uv run` мог синхронизировать окружение без PyTorch и убрать его.
   Для уже подготовленного окружения также описан `uv run --no-sync`.

4. **Рабочие примеры установки — [README.md](README.md).**
   Показаны установка с lock-файлом, запуск списка задач, реального поиска и
   регистрации ядра для готовых ноутбуков. Оставлен способ через pip. Проверка окружения включает
   импорт EPDE и построение пула, чтобы команда `list` не скрывала отсутствующий torch.
