# НИР-1 — H12: инвариант причинного временного члена без дополнительных данных/поколений

**Статус:** новая development-гипотеза, сформулирована ПОСЛЕ анализа ошибок H11 на девяти PDE. В этой серии **запрещено** использовать те же девять PDE как независимое подтверждение нового результата. Их можно использовать для локализации и исправления бага.

## Механизм

Жёсткий H9 target prior внутри EPDE допускает только `u_t`, `u_tt` и др. чистые временные производные объясняемой переменной. При ограниченном RPS числе повторов `simplify_equation` может структурно преобразовать уравнение так, что последняя временная производная исчезнет. Исходный H11 не восстанавливал её при завершении outer loop, а выдавал `RuntimeError('NIR1 H9: no time derivative survived the equation search')`; это проявилось трижды в 36-run frozen validation: две shear IC-связки и одна Gaussian reaction–diffusion.

**H12:** при обнаружении ровно этого терминального инвариантного сбоя пересоздать ОДИН чистый временной derivative token из того же исходного пула. Если достигнут лимит членов, заменить ОДИН член, не увеличивая `max_terms_number`; сбросить устаревшие weights, поставить causal target, повторно выполнить штатный RPS fit. Первая H9/H10/H11 процедура до выхода **не изменена**. При невозможности найти целевой токен по-прежнему честно выдавать ошибку.

H12 = H11 MDL `log(N_time)/N_time`, те же два objectives + H11 финальный выбор `argmin_i objectives[i][0]`, НО opt-in `NIR1_DYNAMIC_REPAIR=1`. Вариант назван `nir1_dynamic_mdl_repair`. Исходный `nir1_dynamic_mdl_select` не затрагивается: флаг включается только для H12 и гарантированно сбрасывается после вызова.

## Ранний smoke: исследовательский, не независимый

[Actions run 38136195891](https://github.com/MakSoS1/EPDE/actions/runs/38136195891), 4 особи × 1 эпоха, все четыре задачи с историческими проблемами завершены `status=ok`:
- Shear `u_t=-x u_x`: найдено точное уравнение (H11 full на seed 0 и 1 аварийно падал);
- Gaussian reaction–diffusion: точная структура;
- Viscous Burgers: модель `u_t≈-0.603 u_x` без нелинейности — ошибка структуры;
- Biharmonic `u_t=-0.018 u_xxxx`: не найдена (текущий MDL наказывает физически необходимый четвертый порядок).

Smoke не даёт научной метрики прироста и не заменяет равнобюджетное full EPDE сравнение.

## Дальнейшее исследование

**Development на девяти уже открытых H11 законах:** при тех же 16×5, одной траектории 81×96, тем же двух optimizer seeds зафиксировать `exact selected`, `truth on front`, failure rate и wall-clock для H12, сравнивать с неизменными 36 первичными H11/baseline архивами (source SHA `eaae906...`). Отличия исходных SHA должны указываться, и результаты **нельзя** выдавать за prospective H11/H12 validation. Никакой ретюнинг MDL после просмотра отдельных исходов этой серии.

**Независимая проверка:** после демонстрации отсутствия регрессий H12 заморозить код и подготовить реально неиспользованные физические профили, желательно со шумом, локальной неидентифицируемостью и высоким spatial derivative order. В научной статье сначала писать проверенные отрицательные исходы H11: **9/18 vs 2/18**, **3 алгоритмические ошибки**, **p=0.21875** cluster-wise.

Возможная новая теория для НИР: `u_t=-c u_x` и `u_t=-u u_x+ν u_xx` **неразличимы на единственной точной travelling wave**. Нужно не подбирать модель по метке, а оценивать **локальный ранг библиотеки и сертификат достаточности наблюдений**. Честный отказ при неидентифицируемости может повысить качество научных вердиктов без увеличения числа наблюдений, но не увеличит искусственно raw exact accuracy.

**Оптимизационный трек E1 зафиксирован, никакой алгоритм ускорения не менялся.** Только форк `MakSoS1/EPDE:nir1`, без изменений upstream.
